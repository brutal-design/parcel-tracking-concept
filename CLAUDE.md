# CLAUDE.md - концепт редизайну «Відстежити посилку»

Мозок проєкту для Claude Code. Читай перед кожною задачею.

## Що це
Концепт редизайну публічної сторінки відстеження посилки Нової пошти, мобільний і десктоп. Робимо його як design engineer: Figma на змінних -> токени в код -> екран у React і Tailwind -> гілка і PR -> рев'ю -> мердж -> прод на моєму Cloudflare.
Як сторінка виглядає зараз - у `before/`: скріни 390 і 1440, публічний текст (`content.md`) і аудит (`AUDIT.md`, 3 речі, які посилюємо).
Мета екрана одна: людина вводить номер і за 3 секунди розуміє, де посилка і до коли її забрати.

## Правила концепту (обов'язково, без винятків)
- Беремо тільки публічне: зміст і структуру сторінки зі скрінів. Код їхнього сайту, логотип і фото не копіюємо.
- Логотип не використовуємо. У шапці текст «Відстеження посилки» і плашка «концепт». Назву компанії згадуємо тільки в рядку концепту.
- Дані тільки демо: номер, адреса, дати, вага позначені «демо-дані». Справжніх API і запитів до чужих сервісів нема.
- Плашка «Redesign concept, not the official Nova Poshta website · Концепт редизайну, не офіційний сайт Нової пошти» на кожному екрані і в 404. Не прибирати ніколи.
- noindex: `<meta name="robots" content="noindex, nofollow">`, `public/robots.txt` з `Disallow: /`, `X-Robots-Tag` у `public/_headers`.
- Жодної аналітики, пікселів і сторонніх скриптів. Шрифт Onest з Google Fonts - єдиний зовнішній ресурс.
- Деплой тільки на мій Cloudflare, проєкт `parcel-tracking-concept` (*.pages.dev). У назвах репо і проєкту не використовуємо чужу торгову марку.
- Тон: «що можна посилити». Їхню сторінку не висміюємо.

## Стек (не міняти без запиту)
- Vite + React 18 + Tailwind CSS 4 (`@tailwindcss/vite`). Без інших бібліотек.
- Токени: Figma Variables (колекція «Трекінг · Tokens») -> `tokens.json` (DTCG, тільки hex) -> `node scripts/tokens.mjs` -> `src/styles/tokens.css` (блок `@theme`). Руками `tokens.css` не правимо.
- Класи Tailwind тільки на токенах: `bg-bg`, `bg-surface`, `text-text`, `text-text-muted`, `border-line`, `bg-accent`, `text-on-accent`... Жодних hex і стандартних кольорів Tailwind (`gray-500`, `red-600`) у компонентах.
- Компоненти в `src/components/`, демо-дані в `src/data/demo.js`.
- Локально: `npm run dev` (http://localhost:5173). Перевірка заголовків: `npm run build`, потім `npx wrangler@4.151.1 pages dev dist --port 8788`.

## Дизайн
- Мобільний перший: від 360px, одна колонка, без горизонтального скролу. Десктоп від 1024px: дві колонки (форма і статус зліва, маршрут і деталі справа).
- Кнопки і поля від 44px, головна кнопка 48px.
- Контраст тексту від 4.5:1, кнопки й іконки від 3:1. Статус не тільки кольором: завжди текст.
- Поле ТТН: підпис над полем, підказка формату, помилка під полем і оголошується скрінрідеру. Номер з пробілами з SMS приймається.
